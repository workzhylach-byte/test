# ASYS.Object — лендинг

Вёрстка по макету Figma «ASYS.Object», страница «Дизайн», фрейм «Версия 2 / С плашкой» (1920px).

## Структура

```
index.html            — страница
assets/css/style.css  — стили (токены в :root, адаптив внизу файла)
assets/css/fonts.css  — подключение шрифтов
assets/fonts/         — Manrope, IBM Plex Sans/Mono, JetBrains Mono (woff2, кириллица + латиница, локально)
assets/js/main.js     — мобильное меню, подсветка пунктов меню, FAQ-аккордеон, проверка формы
assets/img/           — графика из макета (SVG-экспорт из Figma) и обложки ресурсов
```

Сборка не нужна: открывается через любой веб-сервер. При открытии файла напрямую
(file://) браузер не загрузит шрифты из-за CORS.

## Адаптив

- 1920: 1 в 1 с макетом;
- 1200–1919: та же сетка с поля 6.25vw;
- ≤1200: бургер-меню, hero и FAQ в одну колонку, карточки по 2;
- ≤992: «Преимущества» и CTA в одну колонку;
- ≤640: все карточки в одну колонку.
